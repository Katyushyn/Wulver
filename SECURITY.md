# Security policy

## Supported versions

Wulver is pre-release software. Only the latest revision of the default branch
receives security fixes until a versioned support policy is published.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
private GitHub security advisory form and include reproduction steps, affected
versions, impact, and any proposed mitigation.

Never include production credentials, personal data, or a live database in a
report. Maintainers will acknowledge a complete report and coordinate disclosure
after a fix is available.
